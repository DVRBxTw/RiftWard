測試服更新至 0.7.37

## 新功能
- 斷線自動重連：連線中斷後自動重試 6 次，畫面上方顯示重試進度與原因
- 任務中斷線會保留座位 60 秒，連回後直接回到原本的任務（組隊時由電腦暫時代打並自動選升級，單人時任務暫停等你回來）
- 重試都失敗時跳出「連線狀況」提示框，可再次重新連線或改為離線遊玩
- 畫面角落顯示延遲（Ping）與 FPS，依好壞變色；可在設定分別開關，或按 F3 快速切換

## 調整
- 命之座：素材需要與使用中武器同稀有度的同款複本（使用中的武器須為稀世以上）
- 「設定 › 按鍵」列出所有按鍵：新增「本場升級（按住）」與「快速開關 延遲 / FPS」可改鍵，並列出固定按鍵

## 下載
- GitHub 提供測試服啟動器 **RiftWard-Test.exe**，第一次開啟會自動下載遊戲
